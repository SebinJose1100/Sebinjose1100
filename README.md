## 🚀 Featured Project

### Cyclistic Bike-Share Analysis

A data analytics case study analyzing 12 months of bike-share trip data to understand rider behavior, ride duration, day-of-week patterns, and seasonal trends.

**Tools used:**
- Excel
- Power Query
- Excel Data Model
- PivotTables
- Data Visualization

**Key findings:**
- 6.1+ million rides analyzed
- Annual members made more rides overall
- Casual riders had longer average ride durations
- Rider activity varied by day of week and season

Check out my **Cyclistic Bike-Share Analysis** repository to see the complete dashboard, documentation, and analysis.
